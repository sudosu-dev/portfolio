LandAI Assistant

AI-Powered Lease Analysis

A specialized, full-stack web application designed to empower oil and gas professionals by transforming dense legal lease documents into actionable business intelligence. This accelerates due diligence, enhances negotiation strategies, and provides a data-driven edge in a competitive market.

Note: This is a secure application requiring login. Demo credentials are available upon request.

Key Features:

  • AI-Powered PDF Parsing: Upload a lease document, and the system uses the Google Gemini API to intelligently extract key financial and legal terms.
  • Automated Strategic Analysis: Generates detailed reports covering market comparisons, financial projections, and risk assessments.
  • Live Market Data Integration: Pulls real-time county-level sales data from external APIs for up-to-date valuations.
  • Interactive Analysis: Users can re-run reports with custom economic inputs to model different scenarios.
  • Secure & Scalable Backend: Built with a RESTful API featuring JWT-based authentication and a PostgreSQL database.

Technologies: React, Node.js, Express, PostgreSQL, Google Gemini API, JWT Authentication, Vite, Axios.
